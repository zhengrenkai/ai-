# 独立执行卡

> 累的时候只看这一张。
> 作用：把今天压缩成最小可执行版本。

## 今天只保这个

| 项目 | 内容 |
|---|---|
| 最重要的事 | **01:30 前放下手机** |
| 唯一必须动作 | 到家先换衣服训练（最低版） |
| 环境整理 | 每天5-10分钟整理（回家后/睡前） |
| 公众号 | 按周计划产出，今天有任务就做 |
| 可选 | 公众号内容创作 |

## 失手时怎么做

| 情况 | 处理 |
|---|---|
| 回家太累不想动 | 只做引体2×7 + 猫牛式，5分钟搞定 |
| 环境不想整理 | 只整理5分钟，定时器响就停 |
| 想熬夜 | 记住：比昨天早就是进步，01:30也行 |
| 公众号不想写 | 按运营计划节奏走，今天没档期就不做 |

## 不做这些

| 项目 | 说明 |
|---|---|
| 不做交易学习 | 暂停，不考核 |
| 不做现金流稳定线 | 完全暂停，不考核 |
| 不双开 | 一次只做一件事 |

## 完成标准

身体最低版 + 01:30前放下手机 + 环境整理5分钟 = 今天过关。
公众号按节奏走，不强求。
